# v1.0.8 Chrome 版本同步

## 数据来源

- 全局设置：`app_settings` 表，key = `chrome_major_version`，默认 156。
- 模块开关：`app_settings` 表，key = `chrome_sync:<module_id>`。
- 模块 UA 数据源始终是模块自身 `params.chrome_version`，不是全局设置。

## Switch 语义

Switch **只是联动写入授权**：

- 开启：后端立即读取全局版本，写入该模块加密参数 `chrome_version` 并保存；
- 全局版本保存：后端遍历已开启同步的模块，覆盖写入并保存各自 `chrome_version`；
- 关闭：只删除联动授权，不修改当前模块参数，不回滚、不清空。

## UI 约束

- 全局设置页新增 Chrome 主版本号输入，范围 1-999，整数；
- 模块详情页统一渲染同步 Switch；
- `config.params` 无 `chrome_version` 的模块 Switch disabled，tooltip：
  `该模块不支持自定义 Chrome 版本`；
- 同步开启期间模块 `chrome_version` 输入框 disabled，关闭后恢复可编辑。

## 支持模块

当前实现只覆盖：

```text
e-hentai
ikuuu_vpn
```

`trae`、`ehtag_data` 保持固定 UA，不同步 Chrome；其余无 Chrome 参数的模块显示 disabled Switch。

## UA 拼接

模块继续使用自身参数构造：

```text
Chrome/<chrome_version>.0.0.0
```

不得从全局设置直接拼接 UA；全局值只通过后端写入模块参数。

## 持久化

不使用 `localStorage`，不使用 `pinia-plugin-persistedstate`。全局值和模块 Switch 状态均通过现有后端 SQLite `app_settings` 持久化。
